v1.4.0-rc1. Template only. Generate a private device-specific ZIP with scripts/prepare-kernelsu.py.
Installation validates the exact ROM, APKs, XML and existing settings.
Default build changes only Floating Features. --with-memory also packages reversible Settings, component and WRITE_SECURE_SETTINGS activation.
Action performs a manual attempt. After testing, confirm then persist enables recurring boot activation.
Unconfirmed or interrupted boot attempts block retries. Persistent mode confirms mount liveness after 120 seconds, not feature functionality.
No automatic restarts. No repeated automatic attempt after a failure.
--with-homeup-gesture maps three-finger swipe down to installed Save Memory through installed Home Up.
Requires multiple-direction swipe navigation. Restarts Home Up/One UI Home, never Android.
Private preference snapshots stay in the private ZIP. Conflicting mappings or changed snapshots are rejected.
Physical gesture recognition and rebuilt RC soft reboot are unconfirmed.
Current profile pins Smart Suggestions 7.3.31.4; the ActiveMemory hint provider is absent in both 7.3.30.9 and 7.3.31.4.
--with-memory --soft-reboot explicitly authorizes early activation at installation.
This mode pins APK file paths, mounts XML during post-fs-data without Package Manager,
then activates apps after Android starts. Use ksud's soft reboot, not a zygote-only restart.
boot-completed also finishes the stage if the fork suppresses a repeated services callback.
preflight validates without mounting or activating apps. Full soft-reboot behavior still needs device validation.
